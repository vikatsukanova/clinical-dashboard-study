# Clinical interface study

Storybook for the patient-chart design system, organized with atomic design: foundations, atoms, molecules, organisms, templates, and pages. Patient details are fictional.

```bash
npm run storybook
```

Opens at http://localhost:6006. Start at Introduction for the designer rules and the copy-paste snippets. Each component Docs page lists props and source. Each story runs an axe accessibility check in the Accessibility panel.
